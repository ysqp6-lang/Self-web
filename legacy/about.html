我是杨添富,重庆邮电大学国际学院软件工程专业在读学生。 我想尝试让网页脱离常规形式,尽可能创新。

现在 / Now

正在系统补 CSS 与 JavaScript。我的学习方式比较直接:一边学一边把它用在 kysoul.me 上——手写 Three.js 场景、写 GLSL 着色器、给加载过程做动画。 这个站不是作品展示的装饰,它本身就是我的练习场。最近又开始学 Godot, 想自己独立做出一个小游戏。

关注 / Focus

前端前沿视觉与 WebGL / Three.js 三维交互;着色器(GLSL)驱动的实时动效; 以及一个常被忽略的地方——等待的体验。网站加载要花时间,那这段时间就不该是白屏, 所以我做的第一件事是把加载过程变成一场日食。（因为我觉得这真的很帅！）

这个网站 / This Site

从零搭建,没有用任何框架和模板。目前做到的部分:

  • 全屏日食加载动画:与真实资源加载进度联动,加载完成的那一刻正好是日全食,结束时白色光圈炸开进场
  • 鼠标驱动的涡流像素化着色器:读取位移量、速度差与缓动因子,让背景随鼠标实时扭曲
  • 字体自托管与加载策略:不依赖第三方字体 CDN,并在绘制文字纹理前显式等待字体就绪,这样能避免其他人第一次打开时文字不是我的理想字体
  • 目录分层(js / css / fonts)与资源体积优化
