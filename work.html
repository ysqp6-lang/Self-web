iPad 课堂 AI 助手

2026.10 · 真机迭代中 把实时转写、提问识别与 AI 辅助作答串成课堂工作流。

解决的问题

  • 面向课堂中听不清、跟不上与回看困难的场景，开发实时转写、问题标记、录音与 AI 辅助作答；答案可靠性用分级提示呈现。

技术难点与处理

  • 音频回调的线程隔离和转写对象复用导致启动崩溃：调整回调创建方式，每轮重建转写器，并明确停止与资源释放顺序。
  • 转写中间结果反复触发 AI：先合并语句、定稿后再判定，增加调用频率、次数和预算上限；超时与输出截断分别处理。

  • 真机能力探针通过；S1 启停测试记录为 50/50 次成功，未出现崩溃或静默停止。这个结果只覆盖启停稳定性。
  • 60 分钟连续监听、课堂识别与答案质量的系统评测尚未完成；拍照补图重答、二次校验与标注集仍待补齐。音量启发式默认关闭，声纹识别尚未实现。

KyLyn · 对话式 AI 助手

2026.10 · 已部署 · 持续验证 围绕消息可靠性、上下文记忆与可控工具调用，构建持续运行的对话服务。

解决的问题

  • 用 Adapter 分离消息接入与业务逻辑，将记忆、任务、模型调用和发送队列组织成可追踪的服务；跨架构运行采用 Node.js 内置 SQLite。

技术难点与处理

  • 断线补回与在途消息竞争会重复回复或遗漏：加入心跳探测、连接代次隔离、去重和 Outbox 状态机，检查已落库但未回复的消息。
  • 推理输出预算耗尽与结构化元数据缺失：分别诊断空正文、调整预算，并将元数据提取拆成独立调用；对外部动作增加显式确认与范围限制。

已验证与下一步

  • 合并版本的测试记录包含 564 个用例；受控真实发送链路已验证文本、图片与原生表情。测试覆盖不等于全部线上行为已验收。
  • 一次长时间断线的根因尚未确定；延迟任务发送后的状态回写、真实环境情绪标签仍待复核。判断模块处于影子模式，未作为正式决策能力启用。

PSD → SVG · 分层矢量化管线

2026.10 · 样本交付完成 为平涂插画保留图层、透明度与细笔画，用对照渲染评估还原质量。

解决的问题

  • 从 PSD 图层提取颜色与透明度，构造覆盖场、超采样并拟合贝塞尔曲线，保留图层顺序、名称与可见性；另做曲线光顺与体积优化。

技术难点与处理

  • 预模糊会切断细笔画、低占比颜色可能是原画真色：取消预模糊，依据透明度和颜色关系辨别抗锯齿，先核对强制合成图再修正。
  • 不同渲染器的取整差异会造成像素偏差：建立统一对照基准，区分工具伪影与真实色差；需要手工干预时保留可追溯修正。

已验证与边界

  • K-蝴蝶样本交付 13 图层、28 路径；对 PSD 合成图的记录指标为 MAE 0.057、SSIM 0.99975、PSNR 50.2 dB。
  • 独立的曲线光顺实验将文件由 765 KB 降至 423 KB。指标分别对应具体样本，尚未做跨画风、复杂纹理或任意 PSD 的系统评测。

kysoul.me · 个人网站系统

2025 – 至今 · 独立设计与开发 从零手写的个人站点：三维场景 + 着色器动效 + 全屏加载动画，没有使用任何框架或模板。

原来的实现

  • 涡流像素化着色器：自定义 GLSL 片元着色器，基于鼠标位移量、速度差与缓动因子（easeFactor）驱动画面扭曲，指针移动时背景如流体般跟随
  • 全屏日食加载动画：把加载进度映射为日食进程——资源就绪的那一刻正好是日全食，停留 1 秒后白色光圈炸开扩散，穿过光圈直接看到网站
  • 字体与首屏策略：Blanquotey 自托管 + 预加载 + 绘制纹理前显式等待字体就绪，避免首屏文字回落成系统字体
  • 工程整理：JS 按职责拆分为 config / shaders / texture / nav / scene / main，目录分层为 js / css / fonts

2026.10 改版

  • 内容先行：品牌、介绍、导航全部写在 HTML 里，打开即可阅读；首屏没有遮罩、没有阻塞脚本
  • 独立演示：日食与涡流另保留在交互演示页，只有主动点播放时才运行，并尊重「减少动态效果」偏好
  • 图片：背景摄影使用 AVIF / WebP / JPEG 三种格式的响应式派生图，显式设置尺寸并按需加载
  • 可访问性：使用原生链接导航、键盘焦点、适合触控的点击区与跟随系统的深色主题
  • 依赖：去掉 Three.js CDN 与第三方字体请求，站点在断网 CDN 的情况下功能完全不受影响
